# Tamara Clone

A clean, responsive clone of the [Tamara](https://tamara.co/en-SA).

## 📌 Features

- Responsive layout with Flexbox
- Fully static site using only HTML and CSS
- Sections included:
  - Company Footer with contact and links
  - FAQ Section with clean dropdown-like design
- Pixel-perfect spacing and alignment based on the original site

## 🛠️ Technologies Used

- HTML5
- CSS3 (Flexbox)
- No JavaScript or frameworks used
